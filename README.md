One word, as if from a grandma: **sweetheart**. A tiny program that writes exactly one word — the warmest word a grandma would say — to `entry.txt`. No arguments, no network, no dependencies: just the word, validated and read back byte-for-byte.

## Run it

```sh
python3 main.py
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset), prints a short confirmation, and exits 0.
